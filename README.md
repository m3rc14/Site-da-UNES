# UNES Universidade - Projeto Web Front-End

Este projeto consiste no desenvolvimento de um site institucional fictício para a "UNES Universidade". A aplicação foi construída durante os estudos práticos de desenvolvimento web, com o objetivo de fixar conceitos fundamentais de estruturação e navegação em múltiplos documentos web.

## 🚀 Funcionalidades do Projeto
* *Navegação Integrada:* Links estruturados que conectam dinamicamente a Home, a página institucional e a área de contato.
* *Página Institucional:* Seção "Quem Somos" contendo a missão, objetivos e destaques da instituição organizados de forma clara.
* *Formulário de Contato:* Interface estruturada com campos de entrada de dados (email, assunto e descrição) pronta para receber interações dos usuários.

## 🛠️ Tecnologias Utilizadas
* *HTML5:* Estruturação semântica de tabelas, listas, imagens e formulários.
* *CSS3:* Estilização básica e alinhamento visual dos elementos da interface.
* *Ambiente de Desenvolvimento:* Visual Studio Code (VS Code).

Projeto prático desenvolvido para consolidação de fundamentos em desenvolvimento de software e tecnologias web.
